# A Queens Decor

## Setup

For setup instructions, please see the [Fabric Documentation page](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up) related to the IDE that you are using.

## Requirements

This project needs Gradle to run on Java 17 or newer, and the mod sources target Java 21. If you see a message about the Gradle daemon or Loom cache stopping at launch, switch your IDE/terminal Gradle JVM or `JAVA_HOME` to JDK 21.
